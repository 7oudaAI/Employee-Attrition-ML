# Employee Attrition Prediction

## Project Description

This project aims to predict whether an employee is likely to leave the company using machine learning classification algorithms.

The project includes data exploration, preprocessing, model training, hyperparameter tuning, and model evaluation.

## Dataset

The dataset contains information about employees and their work-related and personal attributes.

The target variable is **Attrition**, which indicates whether an employee left the company.

## Data Analysis & Preprocessing

The following steps were performed:

- Exploratory Data Analysis (EDA)
- Checking for missing values and duplicates
- Removing unnecessary features
- Encoding categorical variables
- Splitting the data into training and testing sets
- Feature scaling
- Handling class imbalance using SMOTE

## Machine Learning Models

The following classification models were implemented and compared:

- K-Nearest Neighbors (KNN)
- Naive Bayes
- Logistic Regression
- Decision Tree
- Random Forest

## Hyperparameter Tuning

GridSearchCV was used to find suitable hyperparameters for the machine learning models.

Cross-validation was performed using **5 folds (cv=5)**.

## Model Evaluation

The models were evaluated using:

- Accuracy
- Classification Report
- Confusion Matrix
